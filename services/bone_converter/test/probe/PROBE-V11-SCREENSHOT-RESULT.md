## 4. 结论：渲染链路定位

- **截图证明：V11 重绑定后，实机渲染已是接近自然的 Idle 姿态**——蒙皮顶点跟随骨骼（探针 S3/S4）在渲染层得到了一致验证，没有出现「骨骼/蒙皮整体 60° 偏转」或「lower arm 脱节」。
- 剩余轻微偏差（外展 5°~15°、扭转 ≤12°、左右微不对称 ≤10°）最可能来自 **re-pose 后 bind 基准的少量残留姿态偏移**（骨骼链的微小角度残留），量级在 Idle 动画正常波动范围内，不构成功能性缺陷。
- **对兄弟反馈「仍失败」的可能解释（按可能性排序）**：
  1. 兄弟观察的是**播放前 / 播放起始瞬态帧**（t≈0 或 re-pose 收敛前的过渡帧），该帧可能存在较大的瞬时姿态错误，未被这 4 张「动画播放中稳定相位」截图捕获；
  2. 兄弟目测对「外展 10°~15° + 微扭 10°」的感知放大为「60°」；
  3. 兄弟看到的是不同模型/不同动画下的表现。
- **给阶段 2 的数据基线建议（BDD 断言设计依据）**：以「自然 Idle」为期望——上半身扭转 ≤ 15°、手臂外展 ≤ 20°、上/下臂夹角 150°~180°（无横向断开）、左右差异 ≤ 15°。**不要**断言「0° 偏差」或复刻「60° 错误」。
