## 🏗 项目结构

```
D:/Github/Meta3D/
├── contributes/       ← 扩展贡献包（action / input / ui-control），如 meta3d-action-mod-unit-*
├── protocols/         ← 协议包（extension_protocols / contribute_protocols）
├── packages/          ← 核心包（asset / core / editor-whole / engine-scene / engine-whole / event / interact / three）
├── platform/          ← 平台（backend-4everland / backend-abstract / backend-cloudbase / frontend）
├── services/          ← 服务（meta3d-package / meta3d-platform-publish / meta3d-tool-publish / meta3d-tool-utils）
├── defaults/          ← 默认构建配置（jest / jest-cucumber / commonlib 等）
├── externals/         ← 外部扩展（如 meta3d-react-monaco-editor）
├── examples/          ← 示例
├── demos/             ← Demo
├── doc/               ← 文档
├── utils/             ← 工具
├── templates/         ← 模板
└── 笔记/              ← ← Obsidian 笔记（你在这里）
```

## 🚀 快速命令

```bash
# 单个 contribute 发布（如 upload-model-file）
cd contributes/meta3d-action-mod-unit-upload-model-file
yarn meta3d:publish_dev   # = webpack + gulp publish_local_env_bundle

# 测试（BDD, jest-cucumber）
yarn test   # 或各包内 npx jest

# 类型检查
npx tsc --noEmit
```
